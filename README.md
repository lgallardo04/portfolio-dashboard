# 🚀 Luis Gallardo — Portfolio & CV Dashboard

Interactive, responsive portfolio dashboard showcasing my professional experience, technical skills, and implemented systems.

## ✨ Features

- **Bilingual** — Full English / Spanish language toggle
- **Dark Premium Design** — Modern glassmorphism aesthetic with animated gradients
- **Responsive** — Seamless experience from mobile to desktop
- **Interactive Simulators** — Live demos of real systems I've built:
  - 🛒 **Roble Market POS** — Point-of-sale simulator with product catalog and cart
  - 🏛️ **Araure Tricentenaria** — Census management system simulator
  - 🏋️ **Acarigua Fitness** — Gym class schedule & member management

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)

## 🚀 Deployment

Deployed on [Vercel](https://vercel.com). Simply push to `main` and Vercel handles the rest.
