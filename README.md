## ✨ Key Features

- **🌐 100% Bilingual System** — Full English / Spanish toggle across the entire dashboard with complete localization.
- **💎 Cyber-Glass Aesthetic** — Dark premium glassmorphism design with animated glowing borders and fluid transitions.
- **📱 Mobile-First & Responsive** — Seamless navigation across desktop, tablets, and smartphones, with mobile bottom-navigation and hamburger drawers.
- **⚡ Interactive Live Simulators** — Real-time simulations of actual software architectures built by Luis Gallardo:
  1. 🏥 **CDI Salud Integral** — Clinical Emergency Triage Simulator (**NEWS2** international score calculation, dynamic vitals, risk stratification, and electronic health record history).
  2. 🏛️ **Araure Tricentenaria** — Community Census & Health BI Simulator (Dynamic population pyramid, medication demand ranking, and multi-step census workflow).
  3. 🏡 **Urbanización Los Robles** — Security Gate Log & Access Control (Perimeter security validation preventing duplicate open vehicle entries, and real-time community public services traffic light).
  4. 🛒 **Roble Market POS** — Retail Point-of-Sale & E-Commerce Simulator (Product catalog, reactive cart, delivery/pickup toggle, and simulated Venezuelan Pago Móvil verification with banking webhook).
